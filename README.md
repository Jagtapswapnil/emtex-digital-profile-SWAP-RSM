# EMTEX Digital Portfolio — Swapnil Jagtap

This folder is ready for GitHub Pages.

1. Upload all files and the `assets` folder to a GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/root`, then save.
4. Generate your QR code using the published GitHub Pages URL.

To add Swapnil's photograph later, place the image at `assets/swapnil-jagtap.jpg`. Then replace the initials block in `index.html` with the commented image element beside it.

The WhatsApp, email, Microsoft Teams, website and vCard actions are already configured.
